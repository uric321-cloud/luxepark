# Luxe Park website

Static site for Luxe Park Luxury Apartment Homes, Macon GA. Every push to `main`
publishes it to GitHub Pages via `.github/workflows/pages.yml`.

- Pages: `index.html`, `floor-plans.html`, `tour.html`, `amenities.html`,
  `gallery.html`, `specials.html`, `neighborhood.html`, `contact.html`
- Styles and scripts: `assets/`
- Pricing and availability live only in `assets/data.js`; see `tools/README.md`
  for the updater script.
